## Features

- **Multi-game toolkit** — Each game (e.g., Yu-Gi-Oh!) has its own set of tools
- **Dice Roller** — Quick dice rolling for any game
- **Life Counter** — Track player life points with an intuitive UI
- **Rulings Searcher** — Look up card rulings on the fly
- **Favorites** — Pin frequently used tools for instant access
- **Customizable appearance** — Dark/light/system themes with 6 color presets
- **Grid or list layout** — Choose how your games and tools are displayed
- **Update checker** — Get notified when a new version is available on GitHub

## Getting Started

### Download

Get the latest APK from the [Releases](https://github.com/Prehistoic/TurnZero/releases) page.

### Build from source

```bash
git clone https://github.com/Prehistoic/TurnZero.git
cd TurnZero
./gradlew assembleDebug
```

The debug APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

**Requirements:**
- Android Studio or JDK 17+
- Android SDK 36
